\section*{Summary}
This deliverable identifies and describes the use cases that the TenSyGrid Toolbox is expected and desired to include to serve network operators in assessing the small-signal stability of converter-dominated power grids. Fourteen use cases are cataloged and described, organised into two groups: six use cases already prototyped in an initial web-based Stability Monitor, and eight additional use cases proposed from discussion with operators and other industry agents.

The use cases that are already implemented in an experimental way cover the core stability-analysis workflow: launching a small-signal eigenvalue computation, inspecting the system current status via a dashboard, exploring the eigenvalue spectrum, diagnosing critical oscillation modes through participation factors, verifying bus voltage profiles, and performing $N-1$ contingency analysis with some recommendations.
