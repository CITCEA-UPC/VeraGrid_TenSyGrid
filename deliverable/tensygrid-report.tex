\setkomavar{summary}{This deliverable identifies and describes the use cases that the TenSyGrid Toolbox is expected to support for assessing the stability of converter-dominated power grids. Fourteen use cases are catalogued and organised into two groups: five use cases already prototyped in an initial web-based Stability Monitor and nine additional use cases proposed on the basis of project objectives, existing-tool experience, internal technical discussions, and interviews with industry stakeholders.

The use cases that are already implemented in an experimental way cover the core stability-analysis workflow: launching a small-signal eigenvalue computation, inspecting the system current status via a dashboard, exploring the eigenvalue spectrum, diagnosing critical oscillation modes through participation factors, verifying bus voltage profiles, and performing $N-1$ contingency analysis with some recommendations.}
